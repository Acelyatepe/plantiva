## English

Plantiva is a demo online shop for flowers, plants and gifts. It was built as a portfolio project: there is no real payment or order processing. The site content is in Turkish.

### Features

- Large product catalogue with categories
- Product detail pages with care information
- Cart and favourites
- Order and checkout flow (demo)
- Responsive design for phone, tablet and desktop

### Built with

React · TypeScript · Vite (vinext) · Tailwind CSS · shadcn/ui

### Run locally

```sh
npm install
npm run dev
```
